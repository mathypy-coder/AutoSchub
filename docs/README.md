# AutoSchub — dossier projet

Tout ce qui n'est pas du code vit ici. Chaque dossier a un **responsable** (voir [l'équipe](0-pilotage/equipe.md)),
mais tout le monde peut proposer une modification.

| Dossier | Contenu | Responsable |
| --- | --- | --- |
| [0-pilotage](0-pilotage/) | Équipe, rôles, fonctionnement, décisions, feuille de route globale | Pierre-Yves |
| [1-vision](1-vision/) | Pitch, problème/solution, modèle économique, marché, réglementation | Pierre-Yves |
| [2-produit](2-produit/) | Roadmap de l'app, architecture technique, qualité | Barthélemy |
| [3-commercial](3-commercial/) | Go-to-market, pipeline de partenaires et contacts, présentation | Pierre-Yves + Guillaume |
| [4-finance-juridique](4-finance-juridique/) | Société, pacte d'associés, budget, financement, conformité | Pierre-Yves + Barthélemy |

Le code de l'application est dans [`client/`](../client) (app React) et [`server/`](../server) (API) —
voir le [README technique](../README.md#stack).

## Règles simples

1. **Une source de vérité** : si ce n'est pas écrit ici ou dans une issue GitHub, ça n'existe pas.
2. **Les tâches** vont dans les [issues GitHub](https://github.com/mathypy-coder/AutoSchub/issues) (modèles fournis),
   suivies sur un tableau GitHub Projects — voir [fonctionnement](0-pilotage/fonctionnement.md).
3. **Les décisions importantes** sont consignées dans [0-pilotage/decisions](0-pilotage/decisions/).
4. **Pas de données personnelles** de contacts (téléphone, e-mail privé) ni de documents confidentiels dans le dépôt :
   on y met le nom, l'organisation et le statut, le reste dans un outil privé (CRM, Drive partagé).
