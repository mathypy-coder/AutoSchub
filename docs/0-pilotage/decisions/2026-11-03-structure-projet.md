# Structure du projet et répartition des rôles

- **Date** : 2026-11-03
- **Décideurs** : Pierre-Yves Mathy, Barthélemy Destrée, Guillaume de Mévius
- **Statut** : proposée — à valider ensemble

## Contexte

Le projet passe d'une personne à trois. Il faut un endroit unique pour l'app, la présentation, les contacts,
les décisions et les tâches, et des responsabilités claires.

## Décision

- Le dépôt GitHub AutoSchub est la source de vérité (code + dossier `docs/`).
- Rôles : Pierre-Yves = commercial & business, Barthélemy = technique & gestion de projet,
  Guillaume = réseau & relations institutionnelles (détail dans [equipe.md](../equipe.md)).
- Tâches suivies dans les issues GitHub et un tableau GitHub Projects ; point hebdomadaire de 30 min.

## Conséquences

- Chacun a besoin d'un compte GitHub.
- Les documents confidentiels restent sur un Drive partagé, référencés par lien.
