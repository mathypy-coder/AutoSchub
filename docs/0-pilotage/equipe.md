## Qui décide de quoi (RACI)

R = réalise · A = arbitre / valide · C = consulté · I = informé

| Domaine | Pierre-Yves | Barthélemy | Guillaume |
| --- | --- | --- | --- |
| Vision, positionnement, offre & prix | **A/R** | C | C |
| Roadmap produit & priorités | C | **A/R** | I |
| Développement, hébergement, sécurité des données | I | **A/R** | I |
| Ventes, auto-écoles & moniteurs partenaires | **A/R** | C | C |
| Relations institutionnelles (RACB, fédérations, Régions, GOCA…) | C | I | **A/R** |
| Investisseurs & sponsors | **A** | C | **R** |
| Présentation / pitch deck | **A/R** | C | C |
| Société, pacte, finances, juridique | **A/R** | **R** | C |
| Marque, communication, réseaux sociaux | **A/R** | I | C |

Les décisions qui engagent la société (signature, dépense > seuil à fixer, entrée d'un associé, prix publics)
se prennent **à trois**, consignées dans [decisions](decisions/).
