# Go-to-market

Responsable : **Pierre-Yves** (avec Guillaume pour les portes institutionnelles).

## Ordre d'attaque proposé

1. **Côté offre d'abord** : sans moniteurs, pas d'élèves. Recruter 1–2 écoles ou 5–10 moniteurs dans **une** ville pilote.
2. **Élèves** de cette ville : écoles secondaires, universités/hautes écoles, réseaux sociaux (TikTok, Instagram), parents.
3. **Partenaires crédibilité / distribution** : RACB, assureurs jeunes conducteurs, concessionnaires, fédérations.

## Messages clés

- Élève : « Ton moniteur en 2 minutes, ta théorie dans la poche, ton permis sans galère. »
- Moniteur : « Remplis ton agenda sans prospecter. »
- Partenaire : « Des conducteurs mieux formés, plus vite » (angle sécurité routière).
